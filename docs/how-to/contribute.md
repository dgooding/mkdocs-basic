# Contribute Documentation

## Create a page

1. Add a Markdown file under the appropriate folder in `docs`.
2. Add a clear `#` heading and optional topic tags.
3. Add the page to `nav` in `mkdocs.yml`.
4. Commit the change to GitHub.

## Use callouts

!!! warning "Operational warning"

    Use warnings for actions that can interrupt a service or affect data.

=== "Recommended"

    Keep procedures short, ordered, and testable.

=== "Avoid"

    Do not duplicate content when a link to the maintained source is clearer.
