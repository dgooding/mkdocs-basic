# Getting Started

## Read the site

Use the left navigation to browse sections, or use search to find terms across all published pages.

## Contribute a change

1. Find the page that needs an update.
2. Select the edit icon in the page header.
3. Make the change in GitHub and commit it.
4. The site build validates the update before it is published.

## Work locally

``` powershell
.\.venv\Scripts\python.exe -m mkdocs serve
```

Open the address shown in the terminal to preview live changes.
