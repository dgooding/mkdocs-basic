# Documentation Security Policy

## Do not publish secrets

Never place passwords, API keys, access tokens, connection strings, or private certificates in this site or its Git history.

## Keep access appropriate

Use the repository's GitHub visibility and collaborator permissions to match the sensitivity of the documentation.

## Report an exposure

If sensitive information is committed, revoke or rotate it immediately. Removing text from a later commit does not remove it from Git history.
