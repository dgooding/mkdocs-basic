# Upload Documents

<div class="itsd-page-intro" markdown>

## Add to the shared library

Upload a file to GitHub and it will appear in the ITSD documentation site after publishing.

</div>

[Upload a document](https://github.com/dgooding/mkdocs-basic/upload/main/docs){ .md-button .md-button--primary }

## Three simple steps

1. Select **Upload a document** above.
2. Choose the file from your computer.
3. Select **Commit changes** at the bottom of the GitHub page.

<div class="itsd-status" markdown>

:material-cloud-upload-outline: Your document will be saved to the library and published automatically.

</div>

!!! tip "What can I upload?"

    Upload Markdown documents (`.md`), PDFs, images, and other supporting files.

## Need help?

Ask your ITSD team if you are unsure which document to upload or where it should appear.
