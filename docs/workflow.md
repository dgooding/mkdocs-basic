<div class="itsd-page-intro" markdown>

## How documentation moves through the library

Use this simple flow to add, find, and keep ITSD documentation current.

</div>

<div class="itsd-workflow" markdown>

### 1. Upload

Add one or more Markdown files, PDFs, or supporting files from the [Documents](uploaded-documents.md) page.

### 2. Publish

Commit the upload in GitHub. The site automatically builds and publishes the updated library.

### 3. Find

Use the search bar in the header to find matching documents and open the best result.

### 4. Improve

Use the edit icon on any page to update outdated guidance or correct an error.

</div>
